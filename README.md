# Emprenlazo

Directorio de emprendedores de Córdoba capital y alrededores (30 km).

## Puesta en marcha

1. Copiá `.env.example` como `.env.local` y completá la anon key de Supabase (Project Settings → API Keys).
2. En Supabase → SQL Editor, ejecutá `supabase/schema.sql`.
3. `npm install` y `npm run dev`.

## Estado del proyecto

Base inicial en Next.js 16, React 19 y Supabase. La moderación de emprendimientos aún requiere un panel de administración.
